# Side Navigation Bar

Projeto desenvolvido para praticar a criação de barras laterais de navegação utilizando HTML, CSS e JavaScript.

## 🚀 Objetivo

O objetivo deste projeto foi aprimorar conhecimentos em desenvolvimento front-end, organização de layouts e construção de componentes de navegação modernos.

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Barra lateral de navegação
- Interface moderna
- Navegação interativa
- Layout organizado
- Estrutura responsiva

## 📚 Conceitos praticados

- Flexbox
- Estruturação de layouts
- Responsividade
- Manipulação de interface
- Organização visual
